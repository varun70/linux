    Danger zone

    Linux does what you type, with no undo and often no confirmation. Build one habit and most of these disasters disappear.

    1. Preview

      See what a command will touch first: ls, find … -print, rsync --dry-run, lsblk.

    2. Back up

      Copy the file or take a snapshot: cp -a, sed -i.bak, crontab -l > cron.bak.

    3. Act

      Run the real command, with the narrowest scope you can: one folder, one file, one disk.

    4. Verify

      Check the result: diff, sshd -t, systemctl status, a second login session.
